Como Praticar Conversação com este Deck

• Cada cartão contém apenas uma pergunta para focar na resposta individual do aluno sem sobrecarga cognitiva.

• Use o botão 🇧🇷 ➔ 🇺🇸 / 🇺🇸 ➔ 🇧🇷 para decidir se o aluno lê em português e formula a resposta, ou lê em inglês e traduz a pergunta antes de responder.

• Incentive respostas completas utilizando os tempos verbais adequados: Presente do Indicativo (para hábitos), Pretérito Perfeito (para refeições passadas) e Pretérito Imperfeito (para lembranças de infância).

• Atalhos de teclado: Barra de Espaço para virar o cartão; Seta Direita (→) para avançar e Seta Esquerda (←) para voltar.
